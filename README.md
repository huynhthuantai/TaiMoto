# Tài Moto – GitHub Pages

## Cấu trúc bắt buộc
```
index.html
script.js
style.css
admin/
  index.html
```

## URL
- Website: `/`
- Quản trị: `./admin/index.html` (không dùng `/admin/` tuyệt đối)

Nếu repository là `TaiMoto` của `hthuantai`, URL quản trị dạng:
`https://hthuantai.github.io/TaiMoto/admin/`

## GitHub Pages
Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Lưu ý
Admin chạy hoàn toàn static trên GitHub Pages. Dữ liệu demo/CMS lưu trong localStorage của trình duyệt hiện tại; chưa phải database dùng chung nhiều thiết bị.

Mật khẩu demo: `TaiMoto@123`
